# AI Resume Screening System

## Overview
This project is an AI-powered Resume Screening System developed using Python, Machine Learning, and Natural Language Processing.

## Features
- Resume Upload (PDF)
- Job Description Analysis
- Skill Extraction
- TF-IDF Vectorization
- Cosine Similarity Matching
- Match Percentage Calculation
- Candidate History
- Candidate Leaderboard
- CSV Export
- PDF Report Generation

## Technologies Used
- Python
- Streamlit
- Scikit-Learn
- spaCy
- Pandas
- Plotly
- PyPDF2
