# 🤖 AI Resume Screening System

An AI-powered Resume Screening System developed using **Python, Machine Learning, and Natural Language Processing (NLP)** to automate the resume screening process by comparing candidate resumes with job descriptions.

---

## 📌 Project Overview

The AI Resume Screening System helps recruiters evaluate resumes quickly and efficiently. It extracts text from PDF resumes, identifies technical skills, compares resumes with job descriptions using Machine Learning algorithms, and calculates a compatibility score.

The application provides insights into matched skills, missing skills, candidate rankings, and downloadable reports, making the recruitment process faster and more accurate.

---

## ✨ Features

- 📄 Upload Resume (PDF)

- ❌ Missing Skills Identification

## ⚙️ Project Workflow

1. Upload a PDF resume.
2. Enter the job description.
3. Extract text from the resume.
4. Identify technical skills.
5. Convert text into vectors using TF-IDF.
6. Compare resume and job description using Cosine Similarity.
7. Calculate the match percentage.
8. Display matched and missing skills.
9. Save candidate history.
10. Export results and generate reports.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Resume-Screening-System.git
```

Go to the project directory:

```bash
cd AI-Resume-Screening-System
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
